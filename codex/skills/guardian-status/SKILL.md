# Guardian Status

Run the Guardian Codex adapter instead of raw cleanup or Git mutation:

```bash
node <adapter-path> tool guardian_status '{}'
```

Treat the result as read-only evidence within its bounded operational scope, not a repository-wide cleanliness claim. Additional remotes are names-only unscanned secondary remotes unless native metadata selects an effective authority. Terminal reattach and stale cleanup are plan-only handoffs that require native output and a fresh plan through the relevant mutation tool. Do not run raw cleanup, reset, stash mutation, worktree removal, branch deletion, or filesystem deletion commands.
